# gradle-build

Utiliser bash gradlew, Java 21, le SDK local via local.properties ignoré. Le build est multi-module avec plugins de convention dans build-logic. Lire le catalogue de versions et gradle-wrapper.properties; ne pas rétrograder pour masquer une panne réseau. L’APK vient de androidApp. Lister les tâches avant d’inventer des noms pour Android KMP; distinguer tests hôte et device. Dépôts officiels uniquement, aucune clé de signature de production.

Lire AGENTS.md et docs/DEVELOPMENT_STATUS.md pour les contraintes et vérifications actuelles.
