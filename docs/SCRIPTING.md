# Scripts

Le moteur existant est conservé dans core/data (script et évaluateurs).
La documentation historique détaillée est [scripting.md](scripting.md).
Les tests existants couvrent tokenisation, arbre, simplification, évaluation et formatage.

Aucun nouveau langage ni fournisseur n’est ajouté dans P0. Catalogue central, autocomplétion,
localisation des erreurs et budgets CPU/mémoire restent planifiés. Ne pas interpréter la validation
d’un ZIP comme une validation des scripts contenus dans ses calques.
