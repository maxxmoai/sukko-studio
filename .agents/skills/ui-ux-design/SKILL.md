# ui-ux-design

Partir d’un parcours réel dans feature/editor, feature/importpreset ou feature/iconpackeditor. Présenter les conflits de ressources avant une action destructive, garder les messages traduisibles et séparer explication utilisateur/détails techniques. Studio Glass privilégie hiérarchie, lisibilité et transparence maîtrisée. Valider le résultat sur téléphone sombre et texte agrandi; ne pas livrer des contrôles sans comportement.

Lire AGENTS.md et docs/DEVELOPMENT_STATUS.md pour les contraintes et vérifications actuelles.
