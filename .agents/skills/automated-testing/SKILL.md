# automated-testing

Tests partagés dans commonTest, tests JVM Android dans androidHostTest, tests appareil dans androidDeviceTest. Pour importexport, couvrir fichiers réels temporaires, contenu identique/différent, références après renommage, aperçu absent, archive malveillante et nettoyage. Réutiliser les tests de migrations existants. Fournir commande, résultat et limites; compilation ou présence d’un test ne signifie pas exécution réussie.

Lire AGENTS.md et docs/DEVELOPMENT_STATUS.md pour les contraintes et vérifications actuelles.
